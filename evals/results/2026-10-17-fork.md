## Re-run of task 03 (fork)

Both fork runs queried the same MCPP regions and got 526 and 30 with identical tool results. Neither ran a call-type breakdown, and neither answer says most calls are medical. The baseline agent made one extra query grouping by `type` (Aid Response 302 of 526) and reported it. The only type information the fork agents saw was the all-time top types in describe stats (Aid Response, Medic Response first), which the re-run did not summarize as "most calls". Assessment: run-to-run agent variance, not a parity regression (judged on n=3 baseline and n=2 fork runs). It is variance in whether the agent chose an extra summarizing query, and tool outputs and the guide are unchanged in substance. The expectation still depends on the agent choosing to look; a stronger fire-911 guide or describe hint ("most calls are medical") would make it deterministic.
