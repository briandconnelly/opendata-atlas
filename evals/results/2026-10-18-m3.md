  - its `tools` list is exactly the five `mcp__opendata-atlas__atlas_*` tools;
  - its `mcp_servers` list is exactly `["opendata-atlas"]`;
  - neither list contains `claude_ai` or `claude.ai`;

- Instrument check: the script was first run on four inputs.
  - A clean milestone 2 transcript (`2026-10-18-m2/25-wrong-portal`) passed.

    - one whose first `tool_use` is renamed `Bash`.
- Result: 35 of 35 transcripts pass.
  - Every init lists only the five atlas tools and only the `opendata-atlas` server.
  - No `tool_use` names any other tool.
  - The string `claude_ai` or `claude.ai` appears nowhere in any init event.
- Connectors exist on this account: the session that ran this task had claude.ai Gmail, Google Drive, Google Calendar and Claude Docs connector tools. Curation run 2, which had no `--strict-mcp-config`, also listed them (decisions log, "Curation run 2 outcome").

  - It does not drop plugins. Each init still lists 27 plugins, including plugins that bundle MCP servers (for example `cwms` and `tempest`), but none of those servers is started.
