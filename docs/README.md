# docs

## Current

These describe the project as it is. When they disagree with anything under History, they win.

- [design.md](design.md): the design and contract. The authority for how the server behaves.
- [decisions.md](decisions.md): the log of design decisions, oldest first. A row records why something changed; `design.md` holds the result.
- [upstream-facts.md](upstream-facts.md): probed facts about Socrata that the design depends on.
- [releasing.md](releasing.md): how to cut a release.
- [pack-examples/](pack-examples/): one example claim per claim kind, for writing knowledge packs.

## History

Kept for provenance. Don't follow them as instructions.

- [history.md](history.md): curation, eval and milestone history moved out of `design.md`.
- [release-checklist.md](release-checklist.md): the one-time steps for the first release, `v0.1.0`.
- [superpowers/plans/](superpowers/plans/): the implementation plans for each milestone, all complete.
- [reviews/](reviews/): standards reviews at each milestone.
- [evidence/](evidence/): raw probe output, run transcripts and costs that `decisions.md` and `upstream-facts.md` cite.
